# Fix Model

Given audit findings:
1. Identify the top-priority fix from HOW TO FIX IT section
2. Generate executable Python code implementing that fix
3. Write it to fixes/<model_name>_fix.py
4. Include: data loading, fix application, evaluation code
5. Add a comment at the top: "# Generated by Bloop after scoring X/10"
